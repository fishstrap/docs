Hello and welcome to Fishstrap, a custom Roblox bootstrapper based on Bloxstrap.
Fishstrap gives you a quick and easy way to enhance your Roblox experience. We
offer additional features on top of Bloxstrap's ones, such as:

- Detailed server information using [RoValra](https://www.rovalra.com/)'s API
- Support for Roblox Studio
- Unhidden FastFlags editor
  - You cannot apply FastFlags not present in [the official allowlist][devforum].
- Global Basic Settings editor
- Fishstrap's own game invites
  - They also work with the default Roblox client — [give it a try!][crossroads]
- Cache cleaner, channel switcher and many more!
