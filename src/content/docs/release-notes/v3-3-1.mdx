Small hotfix update, nothing major.

## Fixes

- Fixed the **Details** option for Discord status display showing the game's
  creator instead of the game you're playing.
- Your Discord status shows "Playing Roblox" again by default. Set **Discord
  status display** to **Details** in the Integrations tab if you'd rather show
  the game you're playing.
