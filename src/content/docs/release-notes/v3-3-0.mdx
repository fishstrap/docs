Another day, another Fishstrap update. You can now invite friends to your games
using Discord invites and create desktop shortcuts for your favorite games.

## Additions

### Discord invites

Invite your friends to play any Roblox game with you through Discord. Turn on
**Allow Discord invites** option in the Integrations tab, then send an invite
from any chat or let your friends **Ask to Join** from your profile. Works in
public servers and in private servers you joined from the website.

:::note[It has some limitations!]
1. This feature will not work if whoever wants to join doesn't have Fishstrap
   installed and didn't play a game using Fishstrap with Discord Rich Presence
   enabled at least once.
2. Joining from Discord on mobile or on Linux is not supported.
3. Reserved servers or private servers you joined from inside the Roblox app are
   not supported either.
:::

### Game shortcuts

Paste a Roblox game link in the Shortcuts tab and Fishstrap will add a shortcut
to your desktop, with the game's name and icon, that launches you straight into
it.

## Fixes

- Fixed games using BloxstrapRPC not being able to set custom Discord Rich
  Presence after Roblox renamed its log entry. ([#1510])
- Fixed Fishstrap failing to check for Roblox updates when the first attempt
  didn't go through.

[#1510]: https://github.com/fishstrap/fishstrap/issues/1510
