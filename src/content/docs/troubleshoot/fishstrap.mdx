## System.IO.FileNotFoundException: Could not load file or assembly...

### Causes

- You are missing .NET Desktop Runtime 6.0.36
- Your .NET installation is corrupted or incomplete

### Solution

<Steps>
1. Check installed runtimes through Command Prompt or PowerShell:

   ```bash title="PowerShell"
   dotnet --list-runtimes
   ```

   Look for a line that says `Microsoft.WindowsDesktop.App 6.0.36`. If it's
   missing or Command Prompt/PowerShell says `dotnet` is not a command, the
   runtime isn't installed correctly.

2. Install **.NET Desktop Runtime 6.0.36** (not just .NET Runtime) from
   https://dotnet.microsoft.com/en-us/download/dotnet/6.0
</Steps>

## System.Net.Http.HttpRequestException: ...

### Causes

- Roblox is down at the moment
- You are using a VPN, Cloudflare WARP, or a proxy
- You have incorrect deployment settings in Fishstrap
- You are affected by government censorship or network restrictions

### Solution

<Steps>
1. Visit the [Roblox Status] page to see if Roblox is working.

2. Try disabling/enabling your VPN or proxy and check if the issue persists.

3. Visit the **Deployment** tab in Fishstrap, set your channel to `production`
   and set **Automatic channel change action** to **Never change**.
</Steps>

## FastFlags are not working

### Causes

- You are using FastFlags not on Roblox's official allowlist
- You are expecting Studio behavior in the client

### Solution

As of late 2025, Roblox enforces an allowlist for FastFlags on the client (the
one used to play games). See the allowlist in [this Devforum post][devforum].
All FastFlags still work in Roblox Studio.

## Global Settings tab is grayed out

### Causes

- You haven't launched Roblox with Fishstrap yet to initialize configuration

### Solution

<Steps>
1. Launch any game through Fishstrap at least once to initialize configuration.

2. Close Roblox and reopen Fishstrap's settings to edit Global Settings.
</Steps>

## Stuck on "Waiting for data..."

<Steps>
1. Cancel the launch by pressing **Cancel** button on the bootstrapper window.

2. Try rejoining the same game and see if the issue persists.

3. If the issue does persist, you could try forcing local data by manually
   editing the settings file. Open `%LOCALAPPDATA%\Fishstrap\Settings.json` in
   your preferred text editor and find the property called `ForceLocalData`,
   then change its value to `true`:

   ```json title="Settings.json" del={3} ins={4}
   {
     // ...
     "ForceLocalData": false,
     "ForceLocalData": true,
     // ...
   }
   ```
</Steps>

## "The JSON you've entered does not appear to be valid."

### Causes

- You have an incorrect JSON syntax or misformatted FastFlag entries

### Solution

Use a JSON verification tool like [JSONLint] to validate your JSON.
