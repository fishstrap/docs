This is by far one of the biggest update to Fishstrap we have done. Lot's of features, lot's of fixes, lot's of... stuff.
Might forget to list some stuff in fact so bear with me.

The most obvious change you'll notice is that we've changed icons! We won't go too into it, but I hope you guys like the new icons!

<img src="/Fishstrap.png" height="128" width="128" />

## Integrations

### Borderless Fullscreen (Vulkan)

Allows you to use a fake version of Borderless Fullscreen while using the Vulkan Graphics API. It's not really "borderless fullscreen", but as close as possible.

### StatusDisplay for DiscordRPC

Added StatusDisplay support for DiscordRPC. This now allows you to show what Roblox game you're playing instead of just showing you're playing Roblox.

<img src="/patch_notes_3_1_0_discordrpc.png" />

## Appearance

### Windows Terminal Bootstrapper

A bootstrapper theme inspired by the Windows Terminal. Prints lines to the console, just like a real terminal!

<img src="/patch_notes_3_1_0_terminal_bootstrapper.png" />

### Window Manipulation

A really fun feature. Let's you modify attributes of the Roblox window, allowing you to set a custom icon and title.

<img src="/patch_notes_3_1_0_window_decoration.png" />
<img src="/patch_notes_3_1_0_appearance_page.png" />

## Bootstrapper

### Multi-Threaded Downloads

Fishstrap now has multi-threaded downloads, which should lead to way shorter download times.

### Cleaner Tweaks

Multiple tweaks to the cleaner, now allowing you to specify which directories you want to clean, and more flexible time durations.

<img src="/patch_notes_3_1_0_cleaner_tweaks.png" />

## Deployment

### Custom Roblox Domain

<Aside type="danger">
    **BE CAREFUL AS TO WHAT DOMAIN YOU USE!** This feature can cause unwanted
    side effects if a proper trusted domain isn't used.
</Aside>

Let's you set a custom domain. This domain will be the one Fishstrap/Roblox uses to communicate back and forth. Can help with bypassing geo-restrictions and might possibly also help with latency.

## Miscellaneous

### Search Bar

A handy search bar to help you find settings quickly. Currently, its not that fully fledged, but in coming updates, It should be able to find more setting easier.

<img src="/patch_notes_3_1_0_search_bar.png" />
